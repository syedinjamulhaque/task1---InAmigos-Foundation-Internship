# NGO Awareness Webpage for InAmigos Foundation 🌟

A basic awareness webpage created to showcase **InAmigos'** initiatives, ongoing projects, social impact, and ways people can get involved.

## 📌 About the Project

This project was developed as part of an internship task to create an informative and visually engaging webpage for **InAmigos**. The content was researched from InAmigos' official website and social media platforms, including campaigns, initiatives, and project highlights shared by the team.

## ✨ Features

- Introduction to InAmigos
- Ongoing projects and initiatives
- Social impact and purpose
- Project-related images and visuals
- Call-to-action sections for:
  - Joining
  - Volunteering
  - Supporting InAmigos
- Clean and structured layout
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Objective

The objective of this project is to spread awareness about **InAmigos' work and initiatives** while encouraging people to learn more about the organization and participate in its activities.
